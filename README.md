## 🌟 The 6 Flagship Archetypes

### 1. ⚡ Valence Microsystems (`/valence`)
* **Domain**: Advanced semiconductor packaging & AI accelerator compute dies.
* **Hero Interaction**: 400vh scroll-bound 60fps video scrubber showing monolithic ceramic packaging assembly down to nanometer copper micro-pillars.
* **Interactive Modules**:
  * **Silicon Die Explorer**: Real-time canvas overlay highlighting Tensor Engine, Optical Interconnect, and L2 Cache macros.
  * **Multi-Tier Thermal Metrology**: Dynamic temperature dissipation meters ($850\,\text{W}$ TDP).
  * **Direct Tapeout CTA**: Foundry reservation flow with wafer allocation drawer.

### 2. 🏁 Valkyrie C41 (`/valkyrie`)
* **Domain**: Ultra-endurance carbon gravel racing bicycle.
* **Hero Interaction**: Stealth dark carbon aesthetic with asymmetric telemetry HUD axis ($C_d A$ drag coefficient, $18\,\text{mm}$ seatstay compliance, and live course elevation profiles).
* **Interactive Modules**:
  * **4-Zone Carbon Layup Matrix**: Interactive stress heatmaps (Bottom Bracket, Headtube, Chainstay, Fork).
  * **3-Stage Course Simulator**: Unbound 200, Badlands, and Silk Road terrain compliance tests.
  * **Bespoke Build Studio**: Frame size, cockpit stack, and gravel wheelset customizer.

### 3. 💎 Maison Aurelia (`/aurelia`)
* **Domain**: Haute Horlogerie Astronomical Sapphire Tourbillon.
* **Hero Interaction**: Radical 50/50 split-screen layout. Left viewport stays permanently pinned playing sidereal tourbillon rotation while the right side scrolls through French poetic chapters.
* **Interactive Modules**:
  * **Atelier Lookbook Gallery**: Full-bleed macro craftsmanship photography with zero spec grids.
  * **Movement Oscillography**: 21,600 vph escapement rhythm indicator.
  * **Private Salon Viewing Concierge**: VIP appointment and bespoke engraving request modal.

### 4. 🚙 Voyage Omni-7 (`/voyage`)
* **Domain**: Original Chinese Luxury Smart Electric Crossover SUV.
* **Hero Interaction**: Continuous displacement mouse-drag 360° spatial rotation engine ($65\,\text{px}$ step mapping) across 36 exterior frames ($12\text{ azimuth} \times 3\text{ elevations}$).
* **Interactive Modules**:
  * **8 Luxury Smart-Cockpit Viewpoints**: Forward panorama, Left 45°/90°, Right 45°/90°, Rear cabin, Ambient glass sunroof, and Center console.
  * **Interactive Floating Hotspots**: Live pulsing tags (`[ MATRIX LED BLADE ]`, `[ 21" AERO TURBINE WHEELS ]`, `[ SMART LIDAR POD ]`).
  * **Slide-In Engineering Drawer**: 800V silicon carbide powertrain, $720\,\text{km}$ CLTC range, and Dual Motor $480\,\text{kW}$ metrics.

### 5. 🎧 Aura Planar-1 (`/aura`)
* **Domain**: Flagship Cyber-Acoustic Planar Magnetic Headphones.
* **Hero Interaction**: 400vh scroll-bound exploded transducer scrubber disassembling the open-back beryllium grille, N52 neodymium magnet push-pull matrix, and $0.5\mu\text{m}$ gold-etched diaphragm.
* **Interactive Modules**:
  * **Real-Time Frequency Response Canvas**: Live customizable 20Hz - 40,000Hz frequency response curve (**Harman Target 2026** vs. **Aura Reference Flat** vs. **Sub-Bass Extended**).
  * **Web Audio Tone Generator**: Interactive acoustic tone test playing 30Hz Sub-bass, 1,000Hz Vocal, 8,000Hz Treble, and 16,000Hz Air.
  * **Bespoke Atelier Configurator**: Material selector for hand-stitched Italian Lambskin or Alcantara cushions, Beryllium arch finish, and 4.4mm Pentaconn balanced cables.

### 6. 🧠 Lethe Graph Memory (`/lethe`)
* **Domain**: Temporal, self-correcting agent memory system on HydraDB.
* **Hero Interaction**: Dynamic scroll-velocity tilting canvas with interactive point-in-time time-travel memory playground and Cypher path discovery.
* **Interactive Modules**:
  * **Point-in-Time Recall**: Temporal slider reconstructing agent memory graph state at any historical moment.
  * **SUPERSEDES Graph Invalidation**: Explicit directional edge invalidation replacing naive cosine vector search.
  * **Cypher Path Explorer**: Real-time graph node queries and traversal verification.

## 🎵 Real-Time Audio Engine & Hero Montage

* **Main Page Soundtrack**: Integrated custom soundtrack **`magnific-parguito.mp3`** with smooth volume fade-in and mute transitions.
* **Live FFT Visualizer**: Uses the browser's native **Web Audio API `AnalyserNode`** to calculate 64-bin frequency data in real time, driving the dancing wave equalizer bars in the top navigation bar.
* **Lego Set Build Timelapse Video Loop**: Background hero video (`/assets/lego_build_timelapse.mp4`) rendering a 60fps stop-motion timelapse of modular Lego bricks, glowing cyan energy cores, and gold wing accents assembling with laser alignment guides.

## 🛠️ Local Development & Quickstart

Clone the repository and start the local development server:

```bash
git clone https://github.com/Dami904/antiF.git
cd antiF
python -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

All projects use absolute, project-scoped asset routes compatible with both local static hosting and Vercel edge deployments.

## 📐 Pipeline Principles (The Anti-Cliché Manifesto)

1. **No Cliché Bento Grids**: Every project develops bespoke layouts derived directly from the engineering utility of the product.
2. **Deterministic 60fps Scrubber Performance**: High-efficiency in-memory video blob loading with linear interpolation (Lerp) smoothing for zero frame drops.
3. **Pure Vanilla Delivery**: Zero heavyweight client-side runtime overhead. 100% semantic HTML5, Vanilla CSS / Tailwind utilities, and performant JavaScript.
