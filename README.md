# AntiF — Next-Gen Interactive Web & Studio Experiences

A suite of bespoke, video-scrubbing parallax hero landing pages and interactive 3D drag-to-rotate studio viewers built with high-end aesthetic engineering.

---

## 🌟 Projects Included

### 1. ⚡ [Valence Microsystems](./index.html)
* **Theme**: Precision Semiconductor & High-Density Ceramic Substrates.
* **Architecture**: 400vh sticky scroll video-scrubbing engine, progress-locked mathematical typography, interactive silicon die micro-architecture explorer, and multi-layer substrate metrology.
* **Path**: `index.html` + `assets/`

---

### 2. 🏁 [Valkyrie C41](./valkyrie/index.html)
* **Theme**: Ultra-Lightweight Toray T1100G Carbon Fiber Gravel Endurance Racing Bicycle.
* **Architecture**: Asymmetric live telemetry axis (course distance, 18mm micro-flex frame deflection, $C_d A$ aero curve), interactive 4-zone carbon composite layup matrix, course simulator (Unbound 200, Silk Road, Badlands), and bespoke build configurator.
* **Path**: `valkyrie/index.html` + `valkyrie/assets/`

---

### 3. 🏛️ [Maison Aurelia](./aurelia/index.html)
* **Theme**: Haute Horlogerie & Astronomical Tourbillons in Monolithic Synthetic Sapphire.
* **Architecture**: 50/50 Pinned split-screen runway viewport, poetic French chapter narrative (*Le Monolithe Translucide*, *Le Tourbillon Céleste*, *La Matière Stellaire*), full-bleed lookbook gallery, and private salon concierge reservation.
* **Path**: `aurelia/index.html` + `aurelia/assets/`

---

### 4. 🚙 [Voyage Omni-7 EV Studio](./voyage/index.html)
* **Theme**: Fictional Luxury Chinese 800V Electric Crossover SUV.
* **Architecture**: Drag-to-rotate 360° frame-sequence studio viewer with smooth displacement mapping (12 azimuth angles $\times$ 3 elevations = 36 exterior frames + 8 rich cockpit interior viewpoints), interactive pulsing hotspots, live floating name tag badges, and slide-in hardware specification drawer.
* **Path**: `voyage/index.html` + `voyage/assets/`

## 🚀 Running Locally

Start a local server in the project root:

```bash
python -m http.server 3000
```

Open in your browser:
* **Valence Silicon**: `http://localhost:3000/index.html`
* **Valkyrie Racing**: `http://localhost:3000/valkyrie/index.html`
* **Maison Aurelia**: `http://localhost:3000/aurelia/index.html`
* **Voyage 360° EV**: `http://localhost:3000/voyage/index.html`
